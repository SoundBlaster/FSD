# Xcode File Templates

This directory hosts Xcode File Templates that mirror the FSD slice layout
generated by `fsd-ios create slice`. They give developers `File > New > File`
entry points for the most common FSD building blocks.

## Templates

| Template | Suggested location | Purpose |
| --- | --- | --- |
| FSD Page | `pages/<slice>/ui/<Name>Page.swift` | SwiftUI page entry point. |
| FSD Feature Action | `features/<slice>/model/<Name>Action.swift` | Callable action struct. |
| FSD Entity Model | `entities/<slice>/model/<Name>.swift` | Identifiable value type. |
| FSD Widget | `widgets/<slice>/ui/<Name>Widget.swift` | SwiftUI composition view. |

The CLI generator (`fsd-ios create slice`) remains the canonical way to
scaffold whole slices. The Xcode templates are an Xcode-native convenience
for adding additional files inside an existing slice.

## Install

```sh
make install-xcode-templates
```

Templates are copied to:

```text
~/Library/Developer/Xcode/Templates/File Templates/FSD iOS/
```

Restart any open Xcode windows and the templates will appear under the
**FSD iOS** section of `File > New > File…`.

## Uninstall

```sh
make uninstall-xcode-templates
```

## Notes

- Templates use Xcode's `___FILEBASENAMEASIDENTIFIER___` and `___FILEHEADER___`
  macros so the type and header track the file name set in the dialog.
- Each stub includes Xcode code-completion placeholders (`<#...#>`) that show
  up as editable tokens in the editor. Use Tab to jump between them and
  replace each placeholder with the concrete type, dependency, or body.
- Generated files match the lint rules enforced by `fsd-lint`, provided they
  are saved into the appropriate FSD layer folder.
- To override the install location set `XCODE_TEMPLATES_DIR` when invoking
  the make targets, for example to install into a sandbox during tests.
